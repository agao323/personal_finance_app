# web

The Next.js front end: pages, and the `/api/*` proxy to the private API. It is not run on
its own — `make dev` from the repository root starts it with the API and Postgres.

- Rules for this directory: [`docs/FRONTEND.md`](../docs/FRONTEND.md)
- The map of everything else: [`AGENTS.md`](../AGENTS.md)
- This is Next.js 16, which differs from older versions: read [`AGENTS.md`](AGENTS.md) here first.
