# data/

Real financial exports live here. **Everything in this directory except this file is
gitignored, permanently.**

## Rules

1. Nothing in here is ever committed, copied into `tests/`, or pasted into a prompt.
2. Import scripts read from here. They are written against the *header shape* and tested
   against synthetic fixtures — never against these files.
3. Test fixtures are generated by `api/scripts/seed_synthetic.py`. No fixture anywhere in
   this repo contains a real balance.
4. Financial values are never logged either — the API has a redaction filter and a test that
   asserts it works.

## Why

An import script parsing 500 rows is fine. Pasting 500 rows into an AI session is not —
that puts real financial values into a conversation transcript.

**Code touches the data; context describes the data.**

See `docs/SECURITY.md#handling-real-data-during-development`.
